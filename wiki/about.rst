About & Contributing
====================

ArduConfigurator is a browser-first configurator for ArduPilot. Like Betaflight
Configurator, it is a tool for setup and configuration. It is aimed at
ArduCopter FPV workflows, and also supports Plane, Rover and Sub. It runs in
your browser over Web Serial, and a thin desktop shell reuses the same app. This wiki documents the configurator;
see :doc:`introduction` to get started.

Contributing
------------

The project lives at `github.com/j-w9/arduconfigurator
<https://github.com/j-w9/arduconfigurator>`__. Issues, fixes and pages are
welcome.

This wiki's source is in the ``wiki/`` directory of that repository, written in
reStructuredText for Sphinx. Every page has an **Edit on GitHub** link. To fix
a typo or clarify a step, follow that link, edit the ``.rst`` file and open a
pull request. Keep changes small and scoped. The repository's
``CONTRIBUTING.md`` describes the validation expectations for code
contributions.

Relationship to the ArduPilot wiki
----------------------------------

This wiki **complements** the ArduPilot wiki. It documents the *configurator*:
what each surface does and how to use it. For the firmware itself (flight
modes, tuning theory, parameter meanings, hardware support and flight
behavior), the `ArduPilot documentation <https://ardupilot.org/>`__ is the
canonical reference. These pages link to it wherever a topic is about the
firmware.
