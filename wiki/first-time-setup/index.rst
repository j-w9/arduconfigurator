First Time Setup
================

These pages cover each configuration surface in the order you would normally
work through them on a fresh vehicle. This is the same order as
:doc:`../guided-setup`. Most map to a tab in the app. :doc:`arming` collects
the arming settings and troubleshooting, since arming is where most first
builds get stuck.
